1. Система целиком

Три сервиса, железо и сетевые связи. Фокус MVP — Edge. Backend минимальный, Frontend опционален.

2. Edge — слоистая архитектура

Порты (интерфейсы) объявлены в usecase. Адаптеры их реализуют: стрелка с пустым треугольником направлена вверх, это инверсия зависимостей. Infrastructure — сами внешние ресурсы. Единственный владелец выходов — ControlUsecase, Safety переводит систему в Safe Mode через него.

3. Backend — слоистая архитектура (MVP · минимальный)

Приём пакета с дедупом и отправка алертов в Telegram. GetReadings нужен Frontend и читает данные без UseCase — это зафиксированное исключение. Сущности у Backend свои, общий с Edge только JSON-контракт.
